# 学术论文翻译规则

本规则适用于本技能的所有翻译方向、分批处理、续译、审校和排版修复。用户在当前任务中明确指定的范围与要求优先。所有入口及历史工作流按本规则处理内容保护、全文上下文与字体版式。

## 内容范围与原样保留

- 表格作为完整区域保留，包含标题、表头、单元格、行列标签、数值、单位、表注、脚注、线条与底色。
- 图片和图形作为完整区域保留，包含照片、扫描图、图表、矢量图、坐标轴、刻度、图例、框内文字、图号、图题和图注。可选中的图内文字同样属于保护范围。
- 参考文献区完整保留，包括章节标题、条目编号、作者、题名、出版信息、年份、卷期、页码、DOI、URL、标点及附属注释。根据章节与条目结构确定结束位置，参考文献后的正文或附录继续按内容类型处理。
- 代码块、行内代码、命令、路径、标识符和算法伪代码原样保留，包括注释、字符串、缩进、换行、行号和附属标题说明。正文中解释代码、图表或文献的自然语言照常翻译，引用标记及对象编号沿用原文。
- 保护区域的内容、字体、几何位置、图像质量、矢量对象和链接沿用源 PDF。读取这些内容有助于理解术语、数值及论证。翻译覆盖率与残留原文检查应将其登记为主动保留，并在修复过程中继续保护。

## 全文上下文与段落一致性

- 首次翻译前通读可访问的完整原文，包括标题、摘要、章节、正文、结论、附录及受保护内容。长文档可分批阅读，先形成全文理解再输出译段。节选任务使用可访问的完整输入建立上下文，翻译范围沿用用户指定页码。
- 在临时目录维护 `document-context.md`，记录原文哈希、上下文覆盖范围、主题与论证主线、章节关系、关键定义、实体、缩写、指代关系及跨栏跨页段落续接。对歧义记录源页和块 ID，回查原文后更新。
- 每个译段结合该段、前后段及相关章节的定义理解。`it`、`they`、`this`、`these`、`former/latter` 等指代表达应核对实际先行词，省略主语按上下文补足必要信息。原文仍有歧义时保留相应语义范围，审校记录中标明疑点。
- 按完整语义段落处理跨栏、跨页续句、断词和脚注关联，保持论证顺序、条件范围、对比关系和指代连续。译文写回时维持页序及源块锚点，记录一段对应多个源块的关系。
- 同一概念、实体、方法步骤和反复出现的论断在全文中保持一致。多义词按具体义项登记不同译法，依章节语境选用。对引用、历史观点和作者自身结论保留其各自语境与归属。
- 分批翻译和续译时携带全文上下文、术语表、相邻段落及未完成的段落续接信息。后文补充定义或消除歧义后，回查所有受影响译段，完成修订再写回最终 PDF。

## 标题与摘要

- 标题先判断领域和双关，再翻译。不要逐词硬译。
- 缩写、系统名、数据集名、模型名默认保留原文；首次出现时可加中文解释。
- `LLM` / `LLMs` 在大模型论文中表示 large language model(s)，优先译为“大型语言模型”或保留为 `LLMs（大型语言模型）`，不能译成“法学硕士”。
- `Literature Review` 在学术论文语境中通常是“文献综述”，不是“文学评论”。
- `Human-Centered AI` 在 AI Index / HAI 语境中优先译为“以人为本人工智能”，不要直译成“人类中心人工智能”。
- `Hong Kong Polytechnic University` 是“香港理工大学”，不要误译为“香港大学”。
- `AI sovereignty` 优先译为“人工智能主权”；报告目录中的 `Research and Development` 优先译为“研究与开发”，正文中可按语境使用“研发”。
- 如果标题包含自造词，例如 `LitLLMs`，默认保留原文，并在译注或首次出现处解释。

## 术语

- 翻译前在临时目录建立 `glossary.tsv`，覆盖标题、摘要、关键词、全文定义和高频专有名词。记录源词、统一译名、义项、缩写、首次出现位置、适用语境和待确认事项。
- 原文定义与全文语境决定术语含义，术语表记录已确认译法并约束后续译段。新证据改变既有判断时，更新术语表并回查前文。
- 同一术语的同一义项在全文保持一致，不同义项依据原文语境分别登记译法。
- 对领域术语不确定时，保留英文并加括号解释，比误译更好。
- 用户人工修订术语后，应更新术语表并生成受影响 block 的局部重译计划，不要只在最终译文里手工替换一次。

## 结构与格式

- PDF 结构识别同时登记段落对齐、实测基线步长、首行/悬挂缩进、粗斜体、RGB、引用标记和链接。由非末行左右边界推断两端对齐；居中、右对齐的行首变化不能当作缩进。单行或证据不足时标为 unknown。
- 缩进用排版坐标实现，不在中文中插入空格。中文行距按同类文本统一设置，原文实测值与实际中文值分别记录；用户已选定的中文间距继续适用。
- 引用、链接、上下标及颜色通过可回查的源文到译文锚点保留。正则识别的引用只算候选；非字面样式必须有语义绑定，不能按字符比例猜位置。扫描图像不能凭 OCR 声称已识别字体与颜色。
- 两端对齐须检查实际字形行端点；仅写 CSS 不构成通过。保留自然末行、非中文词内间距、基线、字号和颜色，溢出或过大字间距必须阻止交付。
- 保留章节层级、图表编号、公式编号、引用编号、算法编号、脚注、URL、代码块和数据集名称。
- 公式和符号默认不翻译，只翻译公式周围的解释文字。
- 表格、图片、参考文献和代码按“内容范围与原样保留”完整保护，图表标题说明及表注归入对应保护区域。
- `protected_spans.json` 中列出的元素与上述保护区域均原样保留。保护记录可按页码、块 ID、坐标和原文锚点补充边界，避免覆盖遗漏。
- 分块翻译时，每个 block 都要保留可回查锚点，不得合并到无法追踪原文位置的长段落里。

## 混合区域与写回

- 将提取清单与实际页面对照，识别正文和表格、图片标签、代码、公式或文献条目共用一个块的情况。保护区域包含可选中文字和覆盖图像的隐藏文字层。
- 完整保护块使用 `action: preserve`。正文和保护内容混合时，按实际文字片段与坐标精确分区，保留受保护片段及其源对象，仅替换需要翻译的正文。
- 当前 `session_pdf.py` 校验原始清单及块 ID，计划格式支持整块 `translate` / `preserve`。保留原清单和 ID，另行记录混合块内可翻译区域与受保护片段的坐标。助手计划中将混合块设为 `preserve`，先在临时目录生成只改动完整正文块的候选，再对候选中的混合块进行局部精细排版，最终交付到新的目录。
- 全部应译内容都位于混合块时，直接在源 PDF 的临时副本上进行局部精细排版。助手会拒绝所有决定均为 `preserve` 的渲染计划。混合块的局部处理沿用全篇字体、源块锚点与保护记录，并核对其余内容和页面几何。
- 清除原文与写入译文的范围均限定在可翻译区域内，保留相邻的图形、表格边界和链接。对于工具无法可靠处理的区域，保留原貌并在对话中说明受影响页码与正文范围，继续处理其余内容。

## 全文字体与原版式

- 在排版前检查源文主字体、各文本角色的字号与字重，以及完整译稿所需字形。源字体具备可用文件且覆盖全部译文字形时，优先沿用该字体。嵌入的子集字体须核验实际覆盖范围。
- 原字体缺少目标语言字形或无法可靠复用时，选择风格接近、覆盖目标语言及正文所需字符的同一字体族，统一用于全部可翻译文本。全篇字体一致性优先于逐块复刻原文的不同字体。字体文件与字重、斜体映射作为全篇方案记录，分批与续译沿用该方案。
- 标题、正文、脚注等角色保留原文的字号层级、粗体、斜体、颜色、上下标及强调关系。统一字体族时维持这些样式差异。表格、图片、参考文献、代码和公式保留原字体及原始字形。
- 使用当前助手时，通过同一 `--font` 文件覆盖全部写回块，并检查混排的拉丁字母、数字、标点和目标语言文字是否实际使用选定字体。缺字或隐式逐页换字体时重新选择覆盖完整的字体，复排所有受影响页。
- 保持原页尺寸、方向、页序、栏数、栏宽、页边距、段落边界、对齐、首行和悬挂缩进、行距、段间距、页眉页脚及图文相对位置。译文自然换行以原区域和字号层级为约束。
- 先以原字号和行距试排，溢出时调整忠实完整的措辞，再依据同类文本的统一排版参数解决。保持语义完整和原版面所需的实际调整应记录并在交付时说明。检查助手自动缩放后的实际字号，消除同类段落之间的无依据差异。
- 当前整块助手采用简化样式和自动适配。源文的复杂粗斜体、行距、对齐、缩进及行内保护片段需要结合源页补充本地排版。检查最终 PDF 中的实际字体和页面视觉效果后确认完成。

## 风格

- 默认风格是学术、准确、可读，避免过度口语化，也避免生硬机翻。
- 长句可以拆分，但不能改变逻辑关系、否定范围、实验结论或限制条件。
- 对 `may`、`might`、`suggest`、`indicate` 等保守措辞保持保守，不要强化成确定结论。
- 对 `associated with`、`correlated with`、`association` 等相关性表达保持为“相关/有关联”，不能翻成“导致/造成/引起”。
- 对 `cannot conclude`、`limited evidence`、`insufficient evidence`、`no evidence` 等证据限制必须保留，不能弱化或删除。
- 对作者的局限性、威胁有效性、未来工作等段落保持克制，不替作者补结论。

## 译注

- 译注只用于消除歧义、解释自造词或说明保留原文原因。
- 译注应简短，避免把译文变成扩写综述。

## MQM 质检

- 通读全部译段，核对术语及其义项、缩写、指代对象、主语省略、前后段逻辑和跨页续句。检索同一概念的不同译名，依据原文语境统一并回查相关段落。
- 对照每页源文和成品，核验全部保护区域的文字、图像、字体、位置和链接。保护区域按主动保留计入处理覆盖，正文漏译独立登记。
- 核验全部译文使用的实际字体、缺字情况、同类文本字号、粗斜体、行距与对齐，检查裁切、重叠和跨栏错序。对字体替换及实际版式偏差留下审校记录。
- 质检时按 `accuracy / entity_accuracy / terminology / coverage / omission / addition / style / structure / protected_span / source_quality / rendering` 标注问题类型。
- 对高/中风险问题必须尽量给出 `block_id`、页码、源文证据、译文证据和建议修订；如果是整篇级问题，使用 `document/global` 标记。
- 对 `may`、`might`、`suggest`、`indicate` 等保守措辞被强化的情况，归入 `accuracy`。
- 对公式、引用、DOI、URL、代码、LaTeX 命令丢失或被翻译的情况，归入 `protected_span`。
- 对机构、作者、项目、出版物等专名实体误译，归入 `entity_accuracy`。
- 对页面覆盖缺口、评测样本边界或章节连续性风险，归入 `coverage`。
- 对 PDF 抽取导致的页眉页脚、断词、元数据混排、双栏错序、长英文 token 和异常 heading，归入 `source_quality`，不要混同为模型翻译失败。
- 对译文 PDF/HTML 的兼容汉字、中文缺字、目录错位、脚注漂移和底层原文残留，归入 `rendering`。
